# Getting help

- **Using MCP Tester:** start with the [user manual](https://sebastienrousseau.com/comprehensive-mcp-tester/) or the [README](README.md). The bundled mock server (`npm run mock`) reproduces most server behaviours, including common spec violations, so it is a quick way to see what a correct and an incorrect exchange look like.
- **Something does not work, or you would like a feature:** open an [issue](https://github.com/sebastienrousseau/comprehensive-mcp-tester/issues/new/choose) with the matching template. For a bug, the relevant Log entries help most; tokens and secrets are already redacted there.
- **A security problem:** never in a public issue. Follow [SECURITY.md](SECURITY.md).
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).

MCP Tester is maintained in spare time, so there is no guaranteed response time.
