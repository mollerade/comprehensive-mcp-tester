# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone taking part in the project's issues, pull requests and discussions is expected to follow it.

## Reporting

To report behaviour that breaks the code of conduct, contact a maintainer listed in [CONTRIBUTING.md](CONTRIBUTING.md#maintainers) privately, using the contact details on their GitHub profile. Reports are kept confidential, and the maintainers will respond according to the Covenant's enforcement guidelines.
