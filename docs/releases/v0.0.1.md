## Highlights ⭐️

* **Switching servers is safe mid-load**: a late answer from the server you just left no longer replaces the new server's tools, session or diagnostics, and Disconnect drops requests still in flight.
* **Safer sign-in**: the OAuth flow refuses a non-https authorization endpoint, and untrusted names from a server can no longer inject script into the tool form.
* **Node.js 22 or later**: Node 20 reached end of life on 2026-04-30. The local server can also be installed as an `mcp-tester` command with `make install`, and now starts from symlinked paths, where it used to exit silently.
* **Documented and checked**: a user manual published with each release, decision records, and release files that come with checksums, an SBOM and signed build provenance.
