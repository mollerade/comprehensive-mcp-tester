## Highlights ⭐️

* **Licensed, and safe to run in the open**: MCP Tester is under the PolyForm Noncommercial License 1.0.0, the proxy reaches only the targets an operator allows (no loopback, private or metadata addresses unless listed, redirects checked hop by hop), the Cloudflare Worker is closed until `MCP_TESTER_ALLOWED_TARGETS` is set, and the local server needs a token before it listens beyond loopback.
* **Spec compliance check**: 35 rules graded against the protocol version the server claims, covering JSON-RPC, Streamable HTTP, sessions and handshakes, tools, resources, prompts, paging and the authorization discovery a client follows. The Compliance tab runs it from the page with evidence per rule and a JSON or Markdown export, `npm run compliance -- <url>` prints the same report, and every rule has a mock scenario that breaks it.
* **Sign-in that keeps working**: tokens renew before they expire, with the refresh token or the client credentials; custom client-credential field names; and a testing switch to continue past an issuer mismatch.
* **Verifiable releases from 0.0.1**: each signed tag publishes the built files with checksums, an SBOM and Sigstore provenance, read back after publishing; the version steps by exactly 0.0.1 and `npm run version:bump` sets it everywhere at once.
