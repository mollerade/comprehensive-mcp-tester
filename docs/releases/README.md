# Release highlights

Each release's GitHub notes open with a hand-written **Highlights** section, kept here as `v<VERSION>.md` and written before the release is tagged. Everything else in the notes is generated by `.github/workflows/release.yml`: the list of merged pull requests, new contributors, the SHA-256 checksums of every file, and the full changelog link.

A highlights file holds only this, two to four bullets:

```markdown
## Highlights ⭐️

* **Feature**: one or two plain sentences on what changed for the user.
```
